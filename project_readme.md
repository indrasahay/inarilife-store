# INARI LIFE - Phase 1 Website & CMS

This repository contains the updated development version of the **INARI LIFE** catalogue website and Git-based CMS with dual MRP and Selling Price display, without "Coming Soon" badges.

## Quick Setup & Deployment
1. Create a GitHub repository named `inarilife-store`.
2. Push all files (`index.html`, `admin/`, `data/`) to the `main` branch.
3. Enable GitHub Pages in your repository settings under **Pages** (source: `main` branch / root folder).
4. Access your live store at `https://<your-username>.github.io/inarilife-store/`.
5. Access your CMS at `https://<your-username>.github.io/inarilife-store/admin/`.
